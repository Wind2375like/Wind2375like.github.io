3. Random Number Generation

Every random variate in a simulation is built from i.i.d. U(0,1) numbers; these notes cover where those numbers come from and what makes a generator good.

Motivation. Consider simulating an M/M/1M/M/1M/M/1 queue (Markovian, i.e. exponential, interarrival times; exponential service times; one server). The same idea applies to other distributions: every random variate in a simulation is built from i.i.d. U(0,1)U(0,1)U(0,1) numbers.

Goal of this chapter. Produce a sequence of i.i.d. U(0,1)U(0,1)U(0,1) random numbers, i.e. numbers with p.d.f.

Three alternative sources of “random” numbers

1. True random numbers (from physical experiments)

  • Draw numbered balls from an urn.
  • Electrical circuits: a hardware random number machine, e.g. ERNIE (Electronic Random Number Indicator Equipment).
  • Disadvantages:
    • Not reproducible. Reproducibility matters in simulation: it makes debugging easier, and it gives sharper comparisons when two alternative systems are run on the same random inputs.
    • Difficult to implement.
    • Slow.

2. Pseudo-random numbers — a completely deterministic sequence that is statistically indistinguishable from a true random sequence. This is what simulation uses in practice, and what the rest of the chapter is about.

3. Quasi-random numbers (used in Monte Carlo integration rather than in simulation)

An integral over [0,1][0,1][0,1] is an expectation under U(0,1)U(0,1)U(0,1), because the U(0,1)U(0,1)U(0,1) p.d.f. equals 111 there:

The idea of quasi-random numbers is to replace the random sequence by a deterministic sequence that covers [0,1][0,1][0,1] more evenly; this improves the error rate to order (ln⁡n)/n(\ln n)/n(lnn)/n. 3.1. Random Number Generators (RNGs)

Desired properties of an RNG

  1. Uniformity: the sequence should appear to be uniformly distributed on (0,1)(0,1)(0,1).
  2. Independence: terms in the sequence should not be correlated.
  3. Reproducibility: one must be able to reproduce a particular stream of random numbers (e.g. from a seed).
  4. Fast, with low memory usage.
  5. Long period. A deterministic generator eventually loops. The segment of non-repeating numbers is called a cycle, and its length is the period of the RNG.

3.2.2. Necessary and sufficient conditions for a full-period LCG

Theorem (Hull–Dobell). The LCG zi=(azi−1+c) mod mz_i = (a z_{i-1} + c) \bmod mzi​=(azi−1​+c)modm has full period mmm if and only if

  1. ccc and mmm are relatively prime (their only common divisor is 111);
  2. every prime qqq that divides mmm also divides a−1a - 1a−1;
  3. if 444 divides mmm, then 444 divides a−1a - 1a−1.

Why three conditions. A full-period LCG must visit every one of 0,1,…,m−10, 1, \dots, m-10,1,…,m−1. The test is to look at the sequence “through a coarser lens”: for a divisor ddd of mmm, watch only zi mod dz_i \bmod dzi​modd. If the coarse sequence misses some residue mod ddd, the full sequence misses some value mod mmm. Condition 1 removes the obstruction coming from the increment ccc; condition 2 removes the obstruction coming from the multiplier aaa, one prime q∣mq \mid mq∣m at a time; condition 3 is needed because the prime 222 misbehaves in a way no other prime does, so the lens d=4d = 4d=4 must be checked separately.

Why each condition is necessary.

  • Condition 1. Suppose ccc and mmm share a divisor d>1d > 1d>1. Modulo ddd the recursion becomes zi≡azi−1(modd)z_i \equiv a z_{i-1} \pmod dzi​≡azi−1​(modd), so if z0≡0(modd)z_0 \equiv 0 \pmod dz0​≡0(modd) then every zi≡0(modd)z_i \equiv 0 \pmod dzi​≡0(modd): the sequence never leaves the multiples of ddd. In the example above c=0c = 0c=0, so gcd⁡(c,64)=64\gcd(c, 64) = 64gcd(c,64)=64 and full period is impossible for any seed.
  • Condition 2. Let qqq be a prime dividing mmm. Modulo qqq the map is x↦ax+cx \mapsto ax + cx↦ax+c. If a≢1(modq)a \not\equiv 1 \pmod qa≡1(modq), then 1−a1 - a1−a is invertible mod qqq and the map has a fixed point x∗≡c (1−a)−1(modq)x^* \equiv c\,(1-a)^{-1} \pmod qx∗≡c(1−a)−1(modq). Any seed with z0≡x∗(modq)z_0 \equiv x^* \pmod qz0​≡x∗(modq) stays in that residue class forever, so the period is less than mmm. Hence we need a≡1(modq)a \equiv 1 \pmod qa≡1(modq), i.e. q∣a−1q \mid a - 1q∣a−1; then the map mod qqq is x↦x+cx \mapsto x + cx↦x+c, which does cycle through all qqq residues because gcd⁡(c,q)=1\gcd(c, q) = 1gcd(c,q)=1 by condition 1.
  • Condition 3. Condition 2 with q=2q = 2q=2 only gives aaa odd, i.e. a≡1a \equiv 1a≡1 or 3(mod4)3 \pmod 43(mod4). If a≡3(mod4)a \equiv 3 \pmod 4a≡3(mod4), then applying the map twice mod 444 gives x↦9x+3c+c≡x+4c≡x(mod4)x \mapsto 9x + 3c + c \equiv x + 4c \equiv x \pmod 4x↦9x+3c+c≡x+4c≡x(mod4), so the sequence mod 444 has period at most 222 and cannot visit all four residues. 3.2.3. Two types of LCGs

Type 1: Mixed generators (LCGs with c>0c > 0c>0)

The lesson of RANDU: a long period is necessary but not sufficient. Type 1 and Type 2 generators both need to be tested for uniformity and independence, which is the subject of the next section.

With m≈231m \approx 2^{31}m≈231 and q=3q = 3q=3 this is about 293≈10282^{93} \approx 10^{28}293≈1028.
  • Disadvantage: qqq multipliers to choose instead of one, and the theory for choosing them well is harder. The output sequence still looks like an LCG’s — a linear recurrence with lattice structure — just in qqq dimensions rather than one.

  • Quadratic congruential generator: g(zi−1)=azi−12+bzi−1+cg(z_{i-1}) = a z_{i-1}^2 + b z_{i-1} + cg(zi−1​)=azi−12​+bzi−1​+c, i.e.

    This is the MRG with q=2q = 2q=2 and a1=a2=1a_1 = a_2 = 1a1​=a2​=1. It is very fast (no multiplication) but statistically poor. For i.i.d. uniforms each of the six orderings of three values should occur with probability 1/61/61/6; the Fibonacci generator produces two of them with probability 000.

Practical issues

  1. Period. The period of the RNG should be at least an order of magnitude larger than the total number of random numbers the simulation will consume. Otherwise the sequence wraps around and later parts of the run reuse the same numbers as earlier parts, destroying independence.
  2. Streams. A stream is a segment of the RNG’s cycle starting from a chosen seed. Use a different stream for each replication of a simulation, with the seeds spaced far enough apart that the streams do not overlap. Non-overlapping streams from one long-period generator then behave like independent generators.

  1. Separate streams for separate inputs. Use different streams to simulate quantities that should be independent — e.g. one stream for interarrival times and another for service times. Besides keeping the inputs independent, this synchronizes the random numbers: when two alternative systems are simulated, each can be fed the same interarrival stream and the same service stream, so any difference in the output is due to the systems and not to the random inputs (the “sharper comparison” mentioned at the start of the chapter).

3.4. Testing RNGs

Two kinds of tests:

  • Theoretical tests (number theory). These analyze the generator’s parameters (a,c,m)(a, c, m)(a,c,m) mathematically and say something about the entire cycle — a global property — without generating a single uiu_iui​. Example: the spectral test, which measures how far apart the parallel hyperplanes are on which all kkk-tuples (ui,…,ui+k−1)(u_i, \dots, u_{i+k-1})(ui​,…,ui+k−1​) of an LCG lie (recall RANDU’s 15 planes).
  • Empirical tests (statistics). Generate a finite sample u1,…,unu_1, \dots, u_nu1​,…,un​ and test the null hypothesis

    H0: u1,u2,… are i.i.d. U(0,1).H_0:\ u_1, u_2, \dots \text{ are i.i.d. } U(0,1). H0​: u1​,u2​,… are i.i.d. U(0,1).

    These are only local tests: they examine the part of the cycle that was actually generated, so a defect elsewhere in the cycle goes undetected. H0H_0H0​ has two parts, hence two families of tests: tests for uniformity and tests for independence.
