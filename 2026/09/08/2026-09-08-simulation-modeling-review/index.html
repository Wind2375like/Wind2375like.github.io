Review

A review of the whole course: the key algorithms and formulas of Chapters 3–7, and the format of the final exam.

The first two chapters are preliminaries (Chapter 1: discrete-event simulation; Chapter 2: probability and statistics). Chapter 1’s hand simulation of a single-server queue (§1.2) comes back on the exam (Part I, question 3).

Chapter 3: Random Number Generation

Linear congruential generators (LCGs):

zi=(azi−1+c) mod m,ui=zim.z_i = (a z_{i-1} + c) \bmod m, \qquad u_i = \frac{z_i}{m} . zi​=(azi−1​+c)modm,ui​=mzi​​.

Necessary and sufficient conditions for a full-period LCG (period mmm, Hull–Dobell theorem). For c≠0c \ne 0c=0, the LCG has full period if and only if:

  1. ccc and mmm are relatively prime (their only common divisor is 1);
  2. if qqq is a prime that divides mmm, then qqq divides a−1a - 1a−1;
  3. if 4 divides mmm, then 4 divides a−1a - 1a−1.

(For a multiplicative LCG, c=0c = 0c=0, the period is at most m−1m - 1m−1; it is reached when mmm is prime and aaa is a primitive element modulo mmm: the PMMLCG.)

Testing RNGs:

  1. Test for uniformity: chi-square test. Split [0,1][0, 1][0,1] into kkk subintervals of equal length; fjf_jfj​ = number of the nnn values uiu_iui​ in interval jjj;

    χ2=kn∑j=1k(fj−nk)2;\chi^2 = \frac{k}{n}\sum_{j=1}^k \Big(f_j - \frac{n}{k}\Big)^2 ; χ2=nk​j=1∑k​(fj​−kn​)2;

    reject uniformity at level α\alphaα if χ2>χk−1, 1−α2\chi^2 > \chi^2_{k-1,\,1-\alpha}χ2>χk−1,1−α2​, the (1−α)(1-\alpha)(1−α)-quantile of χk−12\chi^2_{k-1}χk−12​. (The serial test applies the same idea to pairs or ddd-tuples of consecutive uiu_iui​’s.)
  2. Test for independence: runs test (runs up), based on the lengths of the increasing runs in u1,u2,…u_1, u_2, \dotsu1​,u2​,…; the statistic is compared with χ62\chi^2_6χ62​.

Chapter 5: Input Analysis

Goal: select an input distribution to model an input process (e.g. interarrival times, service times). How to do it? Collect data, then three steps:

  1. Collect i.i.d. observations of the input random variable of interest (and check independence, §5.1).
  2. Step I: perform a statistical analysis (summary statistics, histogram, box plot) and hypothesize a distribution family.
  3. Step II: estimate the parameters of the distribution, e.g. by maximum likelihood (MLE):
    1. Construct the likelihood function, the joint density (or p.m.f.) of the data as a function of θ\thetaθ: L(θ)=fθ(x1,x2,…,xn)=∏i=1nfθ(xi)L(\theta) = f_\theta(x_1, x_2, \dots, x_n) = \prod_{i=1}^n f_\theta(x_i)L(θ)=fθ​(x1​,x2​,…,xn​)=∏i=1n​fθ​(xi​) for i.i.d. data.
    2. MLE: θ^=arg⁡max⁡θL(θ)=arg⁡max⁡θln⁡L(θ)\hat\theta = \arg\max_\theta L(\theta) = \arg\max_\theta \ln L(\theta)θ^=argmaxθ​L(θ)=argmaxθ​lnL(θ) (the log turns the product into a sum; set the derivative to 0).
    3. Examples: exponential with mean θ\thetaθ: θ^=xˉ\hat\theta = \bar xθ^=xˉ; geometric (failures before the first success): θ^=1/(1+xˉ)\hat\theta = 1/(1 + \bar x)θ^=1/(1+xˉ); U(a,b)U(a, b)U(a,b): a^=min⁡xi\hat a = \min x_ia^=minxi​, b^=max⁡xi\hat b = \max x_ib^=maxxi​. An approximate CI for θ\thetaθ uses the asymptotic normality of the MLE (§5.5).
  4. Step III: determine the quality of the fit.
    1. Graphical methods
      1. Q–Q plot (compares quantiles; sensitive in the tails)
      2. P–P plot (compares probabilities; sensitive in the middle; also works for discrete data)
    2. Statistical methods (hypothesis tests of H0H_0H0​: the data are i.i.d. with distribution F^\hat FF^)
      1. Chi-square test: compare the observed counts NjN_jNj​ in kkk intervals with the expected counts npjnp_jnpj​:
        χ2=∑j=1k(Nj−npj)2npj\chi^2 = \sum_{j=1}^k \frac{(N_j - np_j)^2}{np_j}χ2=∑j=1k​npj​(Nj​−npj​)2​; reject if χ2>χk−1, 1−α2\chi^2 > \chi^2_{k-1,\,1-\alpha}χ2>χk−1,1−α2​.
      2. K–S test: the largest vertical distance between the empirical c.d.f. and F^\hat FF^:
        Dn=max⁡{Dn+,Dn−}D_n = \max\{D_n^+, D_n^-\}Dn​=max{Dn+​,Dn−​}, Dn+=max⁡i{in−F^(x(i))}D_n^+ = \max_i\{\frac{i}{n} - \hat F(x_{(i)})\}Dn+​=maxi​{ni​−F^(x(i)​)}, Dn−=max⁡i{F^(x(i))−i−1n}D_n^- = \max_i\{\hat F(x_{(i)}) - \frac{i-1}{n}\}Dn−​=maxi​{F^(x(i)​)−ni−1​}; reject if the adjusted statistic exceeds the critical value (ccc, c′c'c′ or c′′c''c′′, by case).
      3. Each test has limitations; given a scenario, you should know which test to apply:

Chapter 6: Output Analysis

Goal: estimate the system (model) performance from simulation outputs.

Idea: construct i.i.d. replications, since the observations within one run are correlated (and not identically distributed).

Terminating simulation (§6.3)

  • Run multiple replications. Observations across runs are i.i.d., so average across runs to construct estimators: XjX_jXj​ = output of run jjj, and the CI is

    Xˉ(n)±tα/2, n−1S2(n)n.\bar X(n) \pm t_{\alpha/2,\,n-1}\sqrt{\frac{S^2(n)}{n}} . Xˉ(n)±tα/2,n−1​nS2(n)​​.

    • Initial conditions: must represent the real system at the start (§6.3.4).
    • Control the estimation precision (§6.3.3):
      • Absolute half-width β\betaβ: from n0n_0n0​ pilot runs, the smallest nnn with tα/2, n−1S2(n0)/n≤βt_{\alpha/2,\,n-1}\sqrt{S^2(n_0)/n} \le \betatα/2,n−1​S2(n0​)/n​≤β, i.e. roughly n≈S2(n0) tα/2, n−12/β2n \approx S^2(n_0)\, t^2_{\alpha/2,\,n-1}/\beta^2n≈S2(n0​)tα/2,n−12​/β2.

Chapter 7: Variance Reduction Techniques

Goal: a smaller Var⁡\operatorname{Var}Var for the same number of runs, i.e. a narrower CI at no additional simulation cost.

  • Common random numbers (§7.1): to compare systems, Z=X1−X2Z = X_1 - X_2Z=X1​−X2​,
    Var⁡(Z)=Var⁡(X1)+Var⁡(X2)−2cov⁡(X1,X2)\operatorname{Var}(Z) = \operatorname{Var}(X_1) + \operatorname{Var}(X_2) - 2\operatorname{cov}(X_1, X_2)Var(Z)=Var(X1​)+Var(X2​)−2cov(X1​,X2​); use the same random numbers for both systems to make cov⁡>0\operatorname{cov} > 0cov>0.
    • Use the inverse transform (monotone, one uuu per variate).
    • Synchronization: the same uuu must be used for the same purpose in both systems (dedicated streams, or generate the variates beforehand).
    • Requires both outputs to react to the uuu’s in the same direction; otherwise it backfires.
  • Antithetic variates (§7.2): for one system,
    • use the uiu_iui​’s in one replication and the 1−ui1 - u_i1−ui​’s in the other;
    • average the pair: Var⁡(X(1)+X(2)2)=σ2+cov⁡(X(1),X(2))2\operatorname{Var}\Big(\frac{X^{(1)} + X^{(2)}}{2}\Big) = \frac{\sigma^2 + \operatorname{cov}(X^{(1)}, X^{(2)})}{2}Var(2X(1)+X(2)​)=2σ2+cov(X(1),X(2))​, which is better than σ2/2\sigma^2/2σ2/2 when cov⁡<0\operatorname{cov} < 0cov<0 (output monotone in the uuu’s).
    • Do not combine with CRN.
  • Control variates (§7.3)
    • μ=E[X]\mu = \mathbf{E}[X]μ=E[X]; YYY can be observed in the same run; ν=E[Y]\nu = \mathbf{E}[Y]ν=E[Y] is known; XXX and YYY are correlated.
    • Xc=X−a(Y−ν)X_c = X - a(Y - \nu)Xc​=X−a(Y−ν) (minus sign), unbiased for every aaa; best a∗=cov⁡(X,Y)/Var⁡(Y)a^* = \operatorname{cov}(X, Y)/\operatorname{Var}(Y)a∗=cov(X,Y)/Var(Y), giving Var⁡(Xc∗)=(1−ρXY2)Var⁡(X)\operatorname{Var}(X_c^*) = (1 - \rho_{XY}^2)\operatorname{Var}(X)Var(Xc∗​)=(1−ρXY2​)Var(X).
    • In practice a∗a^*a∗ is estimated from the runs, which makes the estimator slightly biased.
  • Indirect estimation (§7.4): use known relationships and replace random quantities by known deterministic quantities, e.g. w~(n)=d^(n)+E[S]\tilde w(n) = \hat d(n) + \mathbf{E}[S]w~(n)=d^(n)+E[S] instead of w^(n)\hat w(n)w^(n); with Little’s law (L=λwL = \lambda wL=λw, LQ=λdL_Q = \lambda dLQ​=λd), also L~=λw~\tilde L = \lambda\tilde wL~=λw~ and Q~=λd^\tilde Q = \lambda\hat dQ~​=λd^.
  • Stratified sampling (§7.5): strata Y=1∣Y=2∣⋯Y = 1 \mid Y = 2 \mid \cdotsY=1∣Y=2∣⋯ with known probabilities P(Y=i)P(Y = i)P(Y=i):
    μ=∑iE[X∣Y=i] P(Y=i)\mu = \sum_i \mathbf{E}[X \mid Y = i]\,P(Y = i)μ=∑i​E[X∣Y=i]P(Y=i); estimate each E[X∣Y=i]\mathbf{E}[X \mid Y = i]E[X∣Y=i] by sampling within stratum iii, and combine with the known weights P(Y=i)P(Y = i)P(Y=i).
  • Conditioning (§7.6): μ=E[X]=E[E[X∣Z]]\mu = \mathbf{E}[X] = \mathbf{E}\big[\mathbf{E}[X \mid Z]\big]μ=E[X]=E[E[X∣Z]], where E[X∣Z=z]\mathbf{E}[X \mid Z = z]E[X∣Z=z] can be obtained analytically; use E[X∣Z]\mathbf{E}[X \mid Z]E[X∣Z] instead of XXX.     μ=Ef[h(Y)]=Eg[h(Y) f(Y)/g(Y)]\mu = \mathbf{E}_f[h(Y)] = \mathbf{E}_g\big[h(Y)\,f(Y)/g(Y)\big]μ=Ef​[h(Y)]=Eg​[h(Y)f(Y)/g(Y)]; sample Yi∼gY_i \sim gYi​∼g and use μ^=1n∑ih(Yi) f(Yi)/g(Yi)\hat\mu = \frac{1}{n}\sum_i h(Y_i)\,f(Y_i)/g(Y_i)μ^​=n1​∑i​h(Yi​)f(Yi​)/g(Yi​). Exam format

Bring your book (for the tables: zzz, ttt, χ2\chi^2χ2, K–S critical values) and your calculator.

Part I (3 questions)

  1. Random variate generation (Chapter 4): e.g. derive an inverse-transform, composition, convolution or acceptance–rejection algorithm for a given distribution, and compute its efficiency.
  2. Input analysis (Chapter 5): MLE (write L(θ)L(\theta)L(θ), take the log, differentiate, solve).
  3. Queueing simulation (Chapter 1, §1.2). Given a table of interarrival times AiA_iAi​ and service times SiS_iSi​:
    • draw the sample path (N(t)N(t)N(t) or Q(t)Q(t)Q(t), and the server status);
    • calculate performance measures, e.g. the average delay d^(n)=1n∑Di\hat d(n) = \frac{1}{n}\sum D_id^(n)=n1​∑Di​, the time-average number in queue q^(n)=1T∫0TQ(t) dt\hat q(n) = \frac{1}{T}\int_0^T Q(t)\, dtq^​(n)=T1​∫0T​Q(t)dt, and the server utilization u^(n)=1T∫0TB(t) dt\hat u(n) = \frac{1}{T}\int_0^T B(t)\, dtu^(n)=T1​∫0T​B(t)dt, where B(t)=1B(t) = 1B(t)=1 if the server is busy at time ttt and 0 if idle (one word after “server util” was not caught; these are the standard measures);
    • fit a distribution to the data (e.g. an exponential, by MLE) and perform a hypothesis test (chi-square or K–S).
